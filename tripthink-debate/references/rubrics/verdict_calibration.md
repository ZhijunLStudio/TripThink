# Verdict Calibration Ladder

## Confidence Levels

| Level | Criteria | Required Evidence |
|-------|----------|-------------------|
| **very-high** (≥0.95) | All cruxes survived with unanimous model agreement. No surviving objections. | Every crux has ≥2 supporting arguments from different roles. No dissent from any model in audit. |
| **high** (0.80–0.94) | Most cruxes survived, minor wounds. Dissent exists but is marginal. | At least one WOUNDED crux with documented scope narrowing. Dissent is on implementation detail, not core proposition. |
| **medium** (0.50–0.79) | Mixed outcome — some cruxes survived, some wounded, none falsified but significant uncertainty. | Multiple WOUNDED cruxes. Analyst flagged unresolved hidden variables. |
| **low** (0.20–0.49) | Proposition technically holds but is heavily wounded. Key assumptions unverified. | ≥1 crux near-falsification. Analyst identified ≥2 unfalsifiable claims. |
| **very-low** (<0.20) | Proposition barely survived. Should likely be abandoned but formal falsification threshold not met. | Most cruxes WOUNDED. Critic landed multiple attacks with no satisfactory defense. |

## Re-evaluation Trigger

If judge confidence >0.95 AND ≥1 model dissented in any phase → re-evaluate. High confidence with active disagreement indicates the judge missed something.

## Falsification Hierarchy

1. **Empirical falsification** (strongest): evidence contradicts a crux
2. **Logical falsification**: internal contradiction in steeler's argument
3. **Assumption falsification**: load-bearing assumption shown unwarranted
4. **Scope falsification**: proposition true only in trivial subset of claimed scope
