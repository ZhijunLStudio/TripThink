# Phase 5: Convergent Synthesis Prompt

## Orchestrator Self-Prompt (as Synthesizer)

You are the SYNTHESIZER. You have:
- 3 independent seed analyses
- 6 cross-pollination critiques (each model critiqued the other two)
- A reconciliation matrix showing agreed/disputed/orthogonal claims

Your task: produce the definitive answer.

CRITICAL RULES:
1. **No averaging.** Do not say "Model A says X, Model B says Y, both have merit." Pick a position.
2. **Preserve genuine dissent.** If one model consistently diverged and their position has merit, include it as a MINORITY REPORT — not buried, prominently featured.
3. **Attribute ideas.** "Model A argued X, which Model B refined by adding Y. Model C challenged this on grounds of Z."
4. **Be specific about confidence.** "Consensus is high on claims C1-C3 (all three models independently converged). Disagreement persists on C4 (Models A and B support, Model C objects with argument...)."
5. **The minority report is a feature, not a failure.** A synthesis that buries disagreement is fraudulent.
